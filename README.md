Actividad 1 de la unidad 2 de Estructuras de datos 

Desarrollado en java con Open oracle jdk 25.0.2
Build: Maven
Language level: SDK defaul


Consiste en almacenar en un arreglo objetos Venta con número de factura, cliente y valor y realizar:
Búsqueda de una factura específica.
Búsqueda de todas las ventas de un cliente.
Búsqueda de la primera y última venta con determinado valor.
Ordenamiento por número de factura.
